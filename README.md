# Reopen the Record: Australian Histories

A static, mobile-friendly web app for the sample book.
Open `index.html` from this folder, or serve the directory.

Intended address (not published from this copy):
https://robmac10.github.io/reopen-the-record/

- Cover and contents (thirteen cases in chronological order, also grouped by year level; the cameleers case appears under Year 5 and Year 6)
- Page-turning reader of the book pages, with a text view
- Deep links such as `#p=7` (Start here) and `#case=1`. Older `#case` numbers that do not collide with 1–13 still redirect (for example `#case=42` opens the Batavia case; `#case=14` and `#case=44` both open Mabo).
- Live links to each written case’s app

Keep personal names off the published pages. Do not create a remote repository unless you are asked to publish.
